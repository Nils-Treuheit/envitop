# CPU

**Key: `1`**

The CPU tab gives the processor the full dashboard width. It shows total and
user CPU history, per-core utilization and available temperatures, load
averages, frequency, and the busiest CPU processes.

Scroll the process panel with `j`/`k` or the arrow keys. Return to the summary
with `0` or open the unified [Procs](procs.md) tab.
