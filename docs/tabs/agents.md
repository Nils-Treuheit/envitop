# Agents

**Key: `6`**

Agents shows local Claude Code, Codex CLI, and OpenCode sessions. Its panels
include project and model, activity status, context fill, token and cache use,
recent activity, session details, quota windows, and child processes or ports.

The token summary reports the selected session and observed token rate. Press
`j`/`k` to select another session, `a` to include sessions from the last day,
and `Tab` to move between selectable agent rows. Missing agent history simply
leaves the relevant panels empty.
