# Overview

**Key: `0`**

Overview keeps the main system signals together: CPU and memory summaries,
network and disk activity, GPU usage and processes, and active agent sessions.
The agent and GPU process panels provide selection focus; press `Tab` to move
between those panels and the host process list.

Use the dedicated [CPU](cpu.md), [GPU](gpu.md), [Net](net.md),
[Memory](memory.md), [Procs](procs.md), and [Agents](agents.md) tabs for more
room and subsystem detail.
