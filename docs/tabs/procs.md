# Procs

**Key: `5`**

Procs combines host processes with GPU-only process IDs, joining CPU and RAM
use with GPU index, type, SM activity, memory-bandwidth activity, VRAM, and
runtime where those fields are available.

- Press `f` to search across process fields.
- Press `/` to filter a column, such as `PID/150` or `T/C`.
- Click a column heading to cycle ascending, descending, and default sorting.
- Use `j`/`k` or the arrow keys to change the selected process.

Press `x`, then `y` to request termination of a selected process. Demo mode
disables process termination.
