# GPU

**Key: `2`**

GPU shows utilization and VRAM history beside device telemetry. The telemetry
panel includes temperature, power, fan speed, clocks, driver details, and
power limits where the driver provides them.

The process table reports GPU activity, memory bandwidth, VRAM use, and
runtime. Device and process fields that the driver does not expose remain
unavailable rather than being estimated. See [Procs](procs.md) for GPU and
host process information in one table.
